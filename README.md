# Conveyor Vision 🚀

Автоматическое выявление повреждений на конвейерной ленте с использованием компьютерного зрения и модели YOLOv8.

---

## 📌 Описание проекта

`Conveyor Vision` — это дипломный проект, разработанный в рамках курса **"Основы программирования на Python с применением ИИ"**, с целью создания MVP-продукта, способного:

- Обнаруживать повреждения ленты по фотографии
- Визуализировать найденные дефекты
- Сохранять результаты и вести журнал событий
- Поддерживать гибкую фильтрацию и настройку

---

## 🧠 Используемые технологии

- **YOLOv8n** — обучение модели для детекции 2 классов (`Bad`, `Good`)
- **Streamlit** — лёгкий веб-интерфейс
- **OpenCV + PIL** — визуализация и обработка изображений
- **Ultralytics API** — интеграция обучения и инференса
- **Torch** — база нейронной сети

## 🛠 Установка и запуск

1. Клонируй проект:
   ```bash
   git clone https://github.com/NiyazAkhmetov85/Conveyor_Vision.git
   cd Conveyor_Vision
   ```

2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запусти:
   ```bash
   streamlit run main.py
   ```

## 📦 Модель `best.pt`

- Архитектура: YOLOv8n, 129 слоёв, 3.0M параметров
- Классы:
  - `0: Bad` — повреждённая область
  - `1: Good` — норма
- Сложность: 8.2 GFLOPs
- Используется для локального инференса через `app.py`

---

## 🧪 Результаты обучения

- `mAP50`: **0.932**
- `Recall`: **0.927**
- `Precision`: **0.888**
- Вес модели: ~7 MB
